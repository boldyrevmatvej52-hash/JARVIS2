# 🤖 J.A.R.V.I.S — Just A Rather Very Intelligent System

Голосовой ассистент в браузере, вдохновлённый ИИ из «Железного человека».  
Работает прямо в браузере — без установки, без сервера, без базы данных.

## 🚀 Как запустить

1. Скачайте архив `jarvis.zip` и распакуйте его.
2. Откройте файл `index.html` **в браузере Chrome или Edge** (другие браузеры могут не поддерживать распознавание речи).
3. Разрешите доступ к микрофону и камере, когда браузер спросит.
4. Готово — J.A.R.V.I.S. слушает вас.

> ⚠️ **Важно:** для работы погоды, перевода, генерации картинок и распознавания речи **нужен интернет**. Некоторые функции используют бесплатные внешние API.

## 🛠 Технологии

- **Чистый HTML/CSS/JavaScript** — без фреймворков и сборки.
- **Web Speech API** — распознавание и синтез речи.
- **MediaPipe Hands** — распознавание жестов через камеру.
- **Open-Meteo API** — погода (бесплатно, без ключа).
- **MyMemory API** — перевод (бесплатно, лимит 1000 слов/день).
- **Pollinations.ai** — генерация изображений (бесплатно).
- **Wikipedia / DuckDuckGo API** — ответы на вопросы.
- **localStorage** — сохранение заметок, темы и настроек.
